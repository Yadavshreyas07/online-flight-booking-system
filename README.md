# 📖 About

The **Online Flight Booking System** is a web application developed using **PHP**, **MySQL**, **HTML**, **CSS**, **Bootstrap**, and **JavaScript**.

It automates the airline reservation process by enabling passengers to search flights, reserve seats, complete payments, generate e-tickets, and monitor flight status.

The system also provides an **Admin Dashboard** for managing airlines, flights, passengers, and bookings.
